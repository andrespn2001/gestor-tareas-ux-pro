# TaskFlow AI - Gestor de Tareas Inteligente 🤖

Proyecto Final del Máster de Programación + IA. Es una aplicación web completa que gestiona tareas y utiliza un motor de clasificación inteligente para organizarlas automáticamente.

## 🚀 Demo en vivo
Puedes probar la aplicación funcionando aquí: 
👉 [https://andrespn2001.github.io/gestor-tareas-ux-pro/](https://andrespn2001.github.io/gestor-tareas-ux-pro/)

## ✨ Funcionalidades
- **CRUD Completo:** Crear, leer, actualizar (completar) y eliminar tareas.
- **🧠 Clasificación Inteligente:** Botón mágico (🪄) que analiza el texto (ej. "reunión" → Trabajo, "examen" → Estudio) y asigna la categoría automáticamente.
- **📥 Exportación a CSV:** Descarga un archivo Excel con el historial de tareas.
- **💾 Persistencia:** Los datos se guardan en el navegador (LocalStorage).
- **📱 Responsive:** Diseño adaptado a móviles y escritorio.

## 🛠️ Tecnologías usadas
- **HTML5** semántico.
- **CSS3** (Flexbox, Grid, animaciones y variables).
- **JavaScript (ES6+)**: Programación asíncrona, manipulación del DOM y motor de clasificación local.
